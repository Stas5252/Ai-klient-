## Быстрый старт

Node.js 24, npm, GitHub и Cloudflare Workers Free. Для локальных тестов никаких аккаунтов не нужно:

```sh
npm ci
npm test
npm run typecheck
npm run build
npm run dev
```

Миграции для локального режима:

```sh
npx wrangler d1 migrations apply web-lead-machine --local
```

`npm run live` выполняет настоящий GET официального RSS Workspace, сохраняет кандидатов в **локальную приватную** SQLite `private/verified-live-d1`, повторяет запуск и делает GET-аудит своего сайта. Это не облачный сервис; процесс завершает работу после проверки. При сетевом proxy используйте `NODE_USE_ENV_PROXY=1 npm run live`.

Развёртывание: [DEPLOYMENT.md](DEPLOYMENT.md). Архитектура: [ARCHITECTURE.md](ARCHITECTURE.md). Источники: [SOURCES.md](SOURCES.md). Безопасность: [SECURITY.md](SECURITY.md).

## Поведение

- A+/A: прямые актуальные задачи; неизвестные бюджет/правила отклика требуют проверки.
- B: явный запрос на регулярное сотрудничество с веб-разработчиком.
- C: техническое наблюдение с URL, датой, доказательством и решением.
- D: непроверенная потребность бизнеса; наличие карточки не означает заказ.
- RSS Workspace: каждые 60 минут; облачный cron просыпается каждые 15 минут. Повторная загрузка при приёмке отдельно отмечается в журнале.
- FL.ru: RSS HTTP 200, регулярный обход выключен из-за robots.txt.
- OpenStreetMap: ограниченная географическая выборка опциональна; активность бизнеса и наличие сайта проверяются отдельно. Нет сбора телефонов и личных контактов.
- Публичные Telegram-каналы нельзя читать произвольно через Bot API. Нужен бот в разрешённом чате/канале и whitelist ID.
- Тексты — правила и шаблоны, без платного ИИ. Кейсы не придумываются, ссылка ведёт на реальное портфолио.
- **Нет адаптера отправки предложений третьим лицам.** Одобрение черновика не заменяет согласие на рекламу и правила площадки. Отклик отправляется владельцем вручную в разрешённом интерфейсе.

## С телефона

Откройте [@StanislawWeb_bot](https://t.me/StanislawWeb_bot), нажмите Start, затем `/new` или `/best`. Production webhook установлен. Владелец получает команды `/new`, `/best`, `/business`, `/partners`, `/stats`, `/today`, `/health`, `/pause`, `/resume`, `/sources`, `/settings`, `/export`, `/shutdown`, `/restart`, `/audit URL`.

Кнопки: оригинал заказа, текст для копирования вручную, в работе, отказ, ответил, договорились, оплачено, скрыть, ошибка. Кнопки не отправляют коммерческие предложения. `/shutdown` останавливает сбор и все отправки; подтверждение после shutdown намеренно не посылается. `/restart` возобновляет.

Клиентам: `/start` — 7 вопросов и передача краткого ТЗ владельцу; `/help` — помощь; `/stop`, `/delete_me` — остановка и удаление. Бот честно представляется автоматическим помощником, не назначает цену и не заключает договоры.

`/export` даёт инструкцию получения закрытого JSON через `/api/export` с Bearer ADMIN_API_KEY; скачивание файла непосредственно в Telegram пока не реализовано.

## Дополнительные расходы

Целевой бюджет 0 ₽; платные подписки, API и карта не подключались. Первичная настройка выполнена в новом пустом аккаунте без entitlements. OAuth не даёт чтение billing, поэтому тариф через `/subscriptions` независимо не подтверждён. Реальный сбор занял 72 ms CPU при успешном исходе: это выше опубликованных 10 ms Free и требует оптимизации; стабильность на длинном интервале не доказана. Подробнее [FREE_LIMITS.md](FREE_LIMITS.md).

CRM, SQLite, контакты, ответы и токены исключены из git. Репозиторий пользователя сейчас публичный; в него публикуются только исходники, тестовые фикстуры и агрегированные результаты без контактов.
