# Очередь работ

## Блокируется внешними доступами

- Cloudflare account ID/API token в секретах окружения; script также требует Billing Read для запрета случайного paid deploy.
- Ротация опубликованного в чате Telegram token перед постоянным запуском.
- Deploy Free Worker/D1, установка webhook; настоящее уведомление владельцу после deploy.
- Дождаться следующего cron и проверить автономность после закрытия сессии.
- Проверить реальный CPU и D1 quotas в Free, при необходимости разделить обработку.

## Требует подтверждённых правил/конкретных данных

- Бесплатный способ отклика Workspace для самозанятого и конкретного заказа; автоматическая посылка не реализована.
- Telegram разрешённые группы: бот добавлен, ID, согласие администратора, правила отклика.
- VK/Threads официальные API permissions пользователя; пока ручной поиск.
- Регион/геометрия реального поиска бизнеса, независимые официальные подтверждения сайта/активности.
- Правовая оценка зарубежного D1 перед реальными входящими персональными данными.

## Дальнейшее улучшение в 0 ₽

1. RSS/API из нескольких источников с доказанной политикой, date/expiry verification.
2. Более точная квалификация, бесплатный способ отклика, явное соответствие навыкам и scope.
3. Партнёрские запросы designers/agencies из разрешённых Telegram-групп; разные черновики по профессии.
4. Повторный static audit с подтверждением HTTP ошибки; optional Playwright локально/Actions без покупок, никогда не POST форм.
5. Экспорт файлом в личный Telegram, интерфейс управления реестром/настройками.
6. Business events RSS с отдельной категорией гипотез, без превращения открытия в гарантированный lead.
7. Дешёвый heartbeat вне Worker, только если выбран бесплатный источник мониторинга и реально проверен.
8. Проекты/клиентская база пользователя для matching портфолио и повторных разрешённых обращений.
