## Другие площадки

Threads — B: ручной поиск, API требует Meta авторизацию и необходимых permissions, глобальный бесплатный поиск заказов не подтверждён. VK — B: официальные методы/права и ограничения нужно проверять для конкретного аккаунта и сообщества; токен не предоставлен. Никакого обхода авторизации.

Форумы/стартап-сообщества/доски/агрегаторы — B до конкретного URL и разрешённого RSS/API. Глобального перечня «всех источников» не существует. Включение означает проверку endpoint, robots, условий и бесплатного отклика; нельзя включать произвольные HTML страницы автоматически.

Партнёры: классификатор ищет явное регулярное сотрудничество с разработчиком. Посредник с одним конкретным заказом остаётся категорией A. В проверенной выборке явных партнёров не найдено.

Бизнес-события: новость об открытии не считается заказом. RSS новостей и проверка официальных компаний пока не подключены; автоматическое превращение любых новостей в лиды не реализовано.

## Дополнительные каналы: оценка без публикаций

| Способ | Потенциал | Ручная работа | Действие |
|---|---|---|---|
| Кейсы портфолио с конкретной задачей/результатом | Средний/высокий после накопления | 1–2 часа/кейс | На сайте реально есть /work/rivera-hall, /work/kristina-dimond, /work/n7; не приписывать неподтверждённые результаты |
| SEO страницы услуг | Среднесрочный | 2–4 часа/страницу + подтверждение редактирования сайта | Уже есть /landing, /expert-site, /business-site; основной сайт не менялся |
| Страница партнёрства | Потенциально высокий для повторных проектов | 1–3 часа + согласование | Описать интерфейс передачи макетов, сроки оценки, прозрачное вознаграждение; без обещаний гарантированных заказов |
| Бесплатный мини-аудит | Средний для адресного входящего спроса | 10–20 мин ручной верификации/сайт | Реализован static checker; выводы без ложного утверждения «сайт плохой» |
| Threads/VK кейсы и ответы на вопросы | Неизвестный без эксперимента | 15–30 мин/пост | Черновики вручную, не публиковались |
| Бизнес-профили/каталоги специалистов | Средний/неизвестный | 30–60 мин/площадку | Проверить бесплатную регистрацию и условия, не создавать аккаунты без данных владельца |
| Реферальные и повторные заказы | Вероятно полезный при существующей базе | Низкий после договорённости | Только контакты с согласованным общением, база прошлых клиентов не предоставлена |

Количественные прогнозы заказов без эксперимента не даны. Бесплатный мониторинг не означает бесплатный доступ к отклику, отсутствие комиссий или наличие спроса.
