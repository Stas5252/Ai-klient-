# Безопасность и данные

## Доступ

Telegram webhook проверяет X-Telegram-Bot-Api-Secret-Token; numeric whitelist admin, private chats only для CRM. API закрыт Bearer ADMIN_API_KEY. Public /health показывает только alive; подробные CRM/export/health только admin. Не давайте токен BotFather другим пользователям. Токен, попавший в чат, следует отозвать перед production.

`.dev.vars`, .env, private/, *.private.* исключены из git. Репозиторий сейчас публичный, содержит только исходники/тесты/агрегаты. Ни телефон автора сайта, ни CRM, ни сырые RSS и заявки не публикуются. Система не выполняет shell, JS и инструкции из постов. Черновики с подозрительными инструкциями не формируются.

## Аудит

Только bounded GET. Проверяются scheme, credentials, ports, публичный hostname/IP, DNS A/AAAA через DoH, robots. Redirect не переходится. Закрытые формы, логины, покупки, POST, нагрузка, brute-force и защищённые области запрещены. DNS preflight уменьшает риск SSRF, но DNS rebinding не гарантированно исключён — production fetch Worker должен оставаться без доступа к приватной сети.

Static HTML не подтверждает реальный вид страницы, отправку формы, оплату или поломку адаптива. Network errors — uncertain; HTTP observation подтверждает только полученный статус в указанное время. Не отправлять предложение по непроверенной гипотезе.

## Коммуникации

Рабочий личный Telegram можно использовать для переписки со согласившимися людьми и разрешённых откликов вручную. Bot API не управляет личным аккаунтом и не начинает диалог с произвольным человеком. Нет MTProto credentials, сети аккаунтов, прогрева, прокси или cold spam. Cold draft approval не заменяет согласие на рекламный контакт.

Нельзя автоматически трактовать публичную почту/телефон как согласие на рекламу. Требования 38-ФЗ и 152-ФЗ зависят от содержания/основания обработки; юридическая оценка обязательна владельцу перед расширением исходящих. Система сама не заключает договоры, не обещает скидки/точную цену/срок.

## Хранение

Собираются только исходная публичная публикация, ссылка, бюджет/дата, статус, evidence; для входящих — Telegram chat ID и ответы добровольного опроса. Телефоны/закрытые контакты из каталогов не собираются. Срок: обычные leads до 90 дней, сырые inbox до 1 дня, sessions/notifications до 30 дней. Активные сделки по умолчанию сохраняются до ручного решения; настройка срока требует учёта договорных обязанностей. Suppression — salted hash, чтобы не связаться повторно после удаления.

Cloudflare D1 находится за пределами РФ и сам по себе не обеспечивает локализацию первичного сбора персональных данных граждан РФ. **Правовое соответствие 152-ФЗ этой архитектурой не подтверждено.** Для настоящих клиентских входящих требуется оценка владельца: основание, политика, локализация, уведомления/трансграничная передача по применимым правилам. Бесплатный физический hosting в РФ с webhook/SLA не найден. До разрешения этих вопросов используйте бот как приватный центр уведомлений о публичных заказах; документы клиентов не запрашивайте.

Не публиковать exports и backups; права доступа минимальные; удалить приложение/токены можно в любой момент. Logs содержат только codes/counters/date, не сырые ошибки/секреты/контакты. Копии конфигурации без секретов в git.
