# Свежие бесплатные возможности

Авторизация задачи: пользователь просит максимально автономно настроить поиск свежих заказов в бесплатных соцсетях и биржах, сохраняя бюджет новых сервисов0₽ и запрет спама. Повторное согласование технического дизайна не требуется по прямым указаниям пользователя.

Изменяем существующий поток collectors → qualifier → CRM → owner notifications. Уведомляем только подтверждённо бесплатные кандидаты с оригинальной датой за последний час, неизвестная/будущая/старая дата не считается свежей. Возраст карточки рассчитывается по публикации, не по обнаружению. /new,/best показывают свежие, /archive сохраняет доступ к старым записям.

FL public first-page: только карточки с настоящей индивидуальной отметкой «Для всех». RSSFL запрещён robots; HTML разрешён проверенным robots, соглашение проверяется отдельно. Отсутствие текущих бесплатных карточек означает0, не выдумывание заказов. При запрещении автоматизации сборщик выключается.

Threads/VK: официальные read-only API, новейшие публикации и фильтры времени, секреты без tokenURLs/logs. Без предоставленных доступов не выполнять сеть и не объявлять подключённым. Threads public search требует approved threads_keyword_search: токена недостаточно. Instagram global text search не поддерживается. Kwork robot collection запрещена условиями, поэтому остаётся ручная ссылка. Telegram public scraping не используем, только добровольные прямые заявки с явным согласием.

Расширяем проверенные официальные форумные RSS только после реальных fetch/дат/условий. Период15мин для проверенных бесплатных источников, лимиты/backoff/leases/state постоянные. Тяжёлые этапы профилировать и при необходимости разделять; платный CPU не включать. Доставки только владельцу и consented inbound.
